# コインの2種類化とBGM

状態: 承認済み
承認: 2026-10-31 ユーザーが「実装を進めてください」で承認（直前に仕様と検証方法を提示）。範囲は本spec全体（D-101〜D-105、FR-101〜FR-112、AC-101〜AC-111 と検証方法）
親spec: [`001-slot-tower-defense/spec.md`](../001-slot-tower-defense/spec.md)（承認済み）。本specは 001 のコイン関連の項目を下記のとおり上書きし、BGM を追加する。上書き対象以外は 001 のまま。
依頼: 2026-10-31 ユーザー

## 目的
資金を「スロットコイン」（スロットを回す資金）と「キャラクターコイン」（味方の召喚・強化の資金）に分け、スロットコインを使ってスロットを回し、当たりでキャラクターコインを回収する流れにする。あわせてゲーム画面に BGM を流し、音量を調整できるようにする。

## 確定した決定（ユーザー回答）
- D-101 コインは2種類。キャラクターコインは初期 250、スロットコインは初期 250。（2026-10-31、ユーザー依頼で 1000/500 から変更）
- D-102 スロットはスロットコインで回し、払い出し（当たり）はキャラクターコインとして入る。スロットコインは回すと減り、払い出しでは増えない。（2026-10-31）
- D-103 スロットコインの補充は、敵のドロップとウェーブクリア時のライフボーナス。キャラクターコインはスロットの払い出しと撤退の返還で増える。召喚・強化はキャラクターコインで払う。（2026-10-31）
- D-104 BGM は再生と音量設定を実装する。音源はコード生成の簡易ループ（仮）で、素材の調達・ライセンス記録は本specの範囲外。（2026-10-31）
- D-105 音量はスピーカーアイコンのクリックで段階を切り替え、キーでも上げ下げできる。（2026-10-31）

## 要求
### コイン
- FR-101 キャラクターコインを 250、スロットコインを 250 で始める。この初期値は難易度（設定1〜6）で変わらず、データテーブルで変えられる。（D-101）
- FR-102 スロットの掛け金はスロットコインで払う。スロットコインが掛け金未満なら回せず、スロットコインの表示で拒否が分かる。（D-102）
- FR-103 スロットの払い出し（ボーナス中の払い出しを含む）はキャラクターコインに加算する。リプレイでは次ゲームの掛け金が 0 になる（スロットコインは減らない）。払い出しでスロットコインは増えない。（D-102）
- FR-104 味方の召喚と強化はキャラクターコインで払い、撤退の返還はキャラクターコインに戻る。キャラクターコイン不足の召喚・強化は従来どおり拒否される。（D-103）
- FR-105 敵のドロップとウェーブクリア時のライフボーナスは、スロットコインに加算する。（D-103）
- FR-106 ウェーブをまたいで、2種類のコインをどちらも引き継ぐ。（001 FR-015 の上書き）
- FR-107 画面に2種類のコインの所持数を、見分けられるアイコン・色と数字で表示する。文字は使わない（001 FR-003）。

### BGM
- FR-110 Game シーンで BGM をループ再生する。音源はコード生成の簡易ループ。一時停止中は BGM も止まり、再開で続きから鳴る。（D-104）
- FR-111 音量は 0〜5 の段階（既定 3）で、操作バーのスピーカーアイコンのクリックで段階が切り替わる（最大の次は 0）。キーでも 1 段階ずつ上げ下げできる（割り当ては plan.md）。現在の段階を数字で表示する。0 のときは BGM が鳴らない。（D-105）
- FR-112 BGM の音量は BGM だけに効き、スロットの効果音（レバー・停止・先バレ等）には影響しない。音量はセーブしない（起動ごとに既定に戻る）。（001 の範囲外「セーブ/ロード」に従う）

## 受け入れ条件と検証方法
- AC-101 (FR-101) 新規開始で キャラクターコイン 250・スロットコイン 250 になり、設定1〜6で変わらない。— EditModeテスト
- AC-102 (FR-102, FR-103) スロットを 1 ゲーム回すとスロットコインが掛け金分だけ減り、払い出しはキャラクターコインだけが増える。スロットコインが掛け金未満では回せず、どちらのコインも減らない。リプレイ後の次ゲームはスロットコインが減らない。— EditModeテスト
- AC-103 (FR-104) 召喚・強化はキャラクターコインだけが減り、不足なら拒否される。撤退の返還はキャラクターコインに戻る。スロットコインは動かない。— EditModeテスト
- AC-104 (FR-105, FR-106) 敵のドロップとライフボーナスでスロットコインだけが増え、ウェーブ切り替え後も2種類の所持数が残る。— EditModeテスト
- AC-105 (FR-107) 2種類のコインが画面に区別して表示され、増減とスロットコイン不足の拒否が見て分かる。— Editor画像、文字チェックテスト
- AC-110 (FR-110, FR-112) Game シーンで BGM が鳴りループする。一時停止で止まり再開で続きから鳴る。スロットの効果音は BGM 音量に関係なく鳴る。— PlayModeテスト（再生状態）＋手動確認（聴感）
- AC-111 (FR-111) アイコンのクリックとキーで音量が 0〜5 を巡り、0 で鳴らず、数字表示が合っている。— PlayModeテスト（音量値・再生状態）、Editor画像
